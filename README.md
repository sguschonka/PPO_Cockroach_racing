## 🧠 Алгоритм PPO

Реализован классический **Proximal Policy Optimization** с **Generalized Advantage Estimation (GAE)** для задач с непрерывным управлением.

**Архитектура:**
- **Actor** и **Critic** — полносвязные сети с двумя скрытыми слоями по 128 нейронов (ReLU).
- Выход актора — среднее (`tanh`) и лог-стандартное отклонение для нормального распределения действий.

**Ключевые параметры:**
- **Clipping** ε = 0.1439
- **GAE** λ = 0.9717, γ = 0.9985
- **Entropy bonus** с коэффициентом 0.0204
- **Early stopping** по KL-дивергенции (порог 0.01)
- Максимум итераций политики: 12, ценности: 6

**Гиперпараметры (подобраны с помощью Optuna):**

```python
PARAMS = {
    "lr_actor": 0.0003538,
    "lr_critic": 0.0003047,
    "batch_size": 256,
    "gamma": 0.9985,
    "lambda_gae": 0.9717,
    "entropy_coef": 0.0204,
    "clip_epsilon": 0.1439,
    "max_policy_iters": 12,
    "max_value_iters": 6,
}
```

## ⚡️ Установка и запуск

## 🎮 Как работает среда

- **Наблюдение:** вектор из 7 чисел — угол автомобиля, нормированная скорость и расстояния до препятствий (лидары) по 5 направлениям.
- **Действия:** непрерывный вектор `[руль, газ/тормоз]`, каждый в диапазоне `[-1, 1]`.
- **Награда:**
  - `+0.05 × пройденное расстояние` за каждый шаг
  - `-15` при остановке (перемещение < 0.05)
  - `-100` при выезде на газон (зелёный пиксель)
  - `+200` при финише (серый пиксель) — только если это первый проезд
  - `-50` при повторном проезде финиша
- **Трассы:** случайный выбор PNG-карты из папки `maps/` при каждом сбросе среды.
